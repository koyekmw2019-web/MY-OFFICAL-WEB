# YE KUN Official Website v7.55 — JLPT 180-Point Format (Myanmar)

## ပြင်ဆင်ချက်
- JLPT N1–N5 Mock Exam Result မှာ 25/25 အစား အဓိကရလဒ်ကို 0–180 အမှတ်ပြထားပါတယ်။
- N1–N3: 言語知識 (0–60), 読解 (0–60), 聴解 (0–60); အပိုင်းတိုင်း 19+ မှတ်။
- N4–N5: 言語知識・読解 (0–120), 聴解 (0–60); အနည်းဆုံး 38 နဲ့ 19 မှတ်။
- အောင်မှတ် N1 100, N2 90, N3 95, N4 90, N5 80။ အောင်ဖို့ စုစုပေါင်းနဲ့ အပိုင်းလိုက် သတ်မှတ်ချက်နှစ်ခုလုံး ပြည့်ရပါမယ်။
- Listening ကို စာမေးပွဲနောက်ဆုံးအပိုင်းအဖြစ်ထားပြီး အမှတ်တွက်ပါမယ်။
- Card ၅ ခုလုံး Premium တူညီအမြင့်၊ Book Cover Reflection တည်မြဲပါတယ်။
- PDF နှင့် Page-image PDF assets မထည့်ထားပါ။ YKCR၊ Admin၊ Payment နဲ့ Driving Exams မပြောင်းထားပါ။

## အရေးကြီးတဲ့ ကန့်သတ်ချက်
ဤစာမေးပွဲမှာ မူရင်း Native Text 20 ခု + Listening 5 ခု (25 ခု) ပဲရှိသေးလို့ **တရားဝင် JLPT စာမေးပွဲအရှည်တူမဟုတ်ပါ**။ အပိုင်းတစ်ခုချင်းစီရဲ့ အဖြေမှန်အချိုးကို 60/120 မှတ်ပုံစံသို့ ပြောင်းတွက်ထားတဲ့ **180-point estimate** ဖြစ်ပါတယ်။ JLPT တရားဝင် IRT Scaled Score/အောင်စာရင်း မဟုတ်ပါ။ Website က mock pass-rule simulation ကိုပဲ ဖော်ပြပါတယ်။

N1/N2/N3 Language 16, Reading 4, Listening 5; N4/N5 Combined Language+Reading 20, Listening 5.
